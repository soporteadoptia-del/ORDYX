# Contenido de demostración de Aurevix Music

Pistas originales generadas por síntesis (`scripts/demo-audio.mjs`, licencia CC0) y portadas
generadas con la paleta de Aurevix. No son canciones reales de ningún artista. Las usa la función
`seed-demo` de Supabase para cargar el catálogo de prueba (marcado como «Demo» en la app).
